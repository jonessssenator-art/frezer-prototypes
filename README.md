# Фрезер — прототипы сайта

Четыре варианта дизайна сайта площадки «Фрезер»
(Дом культуры завода «Фрезер», Москва, ул. 2-я Фрезерная, 3).

**Смотреть:** https://atmosferaprintt.github.io/frezer-prototypes/

| Вариант | Характер | Страниц |
|---|---|---|
| [Афиша](afisha/) | Кремовая бумага, красная типографская краска, ретро-афиша | 4 |
| [Вечер](vecher/) | Тёмный премиум, свет от фотографий | 4 |
| [Ремесло](remeslo/) | Белый фон, чёрные инверсии, спокойный минимализм | 4 |
| [Пластинка](plastinka/) | Игривый: метафора виниловых пластинок | 1 (главная) |

Все варианты используют общие ассеты из `shared/` и построены на фирменном
стиле из брендбука: цвета, логотипы, фирменные элементы, шрифты
Source Sans 3 + Cormorant Garamond + Alistair Signature.

## Что важно знать

- **Цен на сайте нет** — по решению заказчика.
- **Отзывы не выдуманы.** Площадка ещё не открылась, поэтому вместо отзывов
  честный блок: они появятся на Яндекс.Картах после первых событий.
- **Заглушки, которые ждут данных от заказчика:** ник Telegram для заявок,
  ссылка на карточку в Яндекс.Картах, виджет карты, бэкенд формы.
- **Фотографий не хватает** на все шесть форматов: нужны кадры велком-холла
  первого этажа и пространства второго этажа.

Чистый HTML, CSS и ванильный JavaScript. Без сборщиков и библиотек.
